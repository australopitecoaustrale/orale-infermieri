# Orale Infermieristica

Sito di studio per la prova orale del concorso unico regionale Infermieri della Regione Puglia 2026: schede, flashcard, quiz, domande d'orale con risposta estesa, casi clinici e progressi.

Ogni mattina vengono aggiunte nuove domande nel file `giorni.json`.

Il sito è pubblicato con GitHub Pages dalla cartella principale del ramo `main`.
